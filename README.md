# JPAgentManager

複数の Mac・複数のリポジトリで動いている Claude Code（主に VSCode 拡張）を、メニューバーから一覧するアプリ。クリックするとそのセッションが前面に出る。

- 状態: P1（1台の Mac で一覧・状態・前面化・通知）を実装済み
- 形態: macOS 26 以上のメニューバー常駐アプリ（NSStatusItem ＋ NSPanel、中身は SwiftUI）
